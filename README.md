# BamBook

Telegram-бот для поиска музыки, личной библиотеки и импорта треков из музыкальных сервисов.

## MVP

- Mini App открывается из кнопки меню BamBook в Telegram; в нём есть единый блок плеера, поиск, библиотека, плейлисты без заданного лимита и тема Telegram. Поддерживаемые источники используют один закреплённый плеер: YouTube — видимый видеоплеер, SoundCloud — официальный аудиовиджет, Jamendo — полный разрешённый трек, Apple Music — короткое превью.
- `/search` — после команды бот попросит текст запроса; можно и просто отправить сообщение `Kanye West Gold Digger`.
- Поиск собирает и ранжирует совпадения Apple Music/iTunes, Spotify, YouTube, SoundCloud и Jamendo. В Mini App YouTube проигрывается видимым официальным видеоплеером, SoundCloud — официальным аудиовиджетом, Jamendo — полным разрешённым треком, Apple — коротким превью. Внешние плееры могут применить собственные ограничения входа и доступности.
- Telegram Guest Mode обрабатывается как отдельный тип обновления: при упоминании BamBook в группе бот отвечает одним сообщением с результатами поиска. Личная библиотека и плейлисты в гостевой чат не передаются.
- `/save номер` — сохранить результат поиска в личную библиотеку.
- `/library` — показать сохранённые треки.
- `/import ссылка` — сохранить ссылку на трек или плейлист из Spotify, Яндекс Музыки, YouTube Music и других сервисов.
- `/remove номер` — удалить трек из библиотеки.
- `/playlists`, `/playlist_new название`, `/playlist_add номер_плейлиста номер_трека`, `/playlist_show номер`, `/playlist_remove номер_плейлиста номер_трека`, `/playlist_delete номер` — управлять личными плейлистами в боте.
- **Аккаунт** в Mini App — тариф BamBook Free/Plus, подключённые Telegram-каналы и свежие посты.
- Бесплатно можно подключить до 3 новостных Telegram-каналов и читать ленту за последние 7 дней. BamBook Plus снимает лимит каналов и открывает архив на 90 дней; по умолчанию подписка стоит 100 Telegram Stars в месяц и автоматически продлевается. Цена меняется через `PREMIUM_PRICE_STARS`.

Библиотека и любое количество плейлистов хранятся в SQLite. Можно создавать плейлисты в Mini App или в боте; найденные треки добавляются в них через интерфейс или команды.

Чтобы подключить новостной канал, сначала добавь BamBook в него участником, затем укажи `@username` в Mini App → **Аккаунт**. Посты начнут попадать в ленту после подключения; старые публикации Telegram Bot API не предоставляет.

Ссылки Spotify, Яндекс Музыки, YouTube Music, Apple Music и аудиокнижных сервисов можно сохранить в аккаунте. Сейчас это сохранение ссылки, не OAuth-вход и не импорт содержимого. Полноценное подключение аккаунта требует официального API и зарегистрированных ключей конкретного сервиса; подписка Plus эти ключи не заменяет.

Если отправить боту аудиофайл (как аудио, голосовое или документ с аудио MIME-типом), он перекодирует его в AAC-LC 128 кбит/с, 44,1 кГц, stereo, контейнер M4A и пришлёт как аудио в Telegram. FFmpeg должен быть установлен и доступен в `PATH`; можно задать `FFMPEG_BINARY` в `.env`. Обычный Bot API ограничивает скачивание входящих файлов 20 МБ, а отправку — 50 МБ. Каталожные API стриминговых сервисов не отдают полную музыку для скачивания: по результату поиска BamBook пока может показать карточку и источник, но для конвертации полный исходный аудиофайл должен быть загружен пользователем или получен из разрешённого источника.

В Telegram-чате BamBook отправляет только аудио: разрешённые к скачиванию CC0-треки Jamendo либо короткие официальные превью Apple Music. Mini App проигрывает YouTube как видео через официальный видимый iframe-плеер, а SoundCloud — через их аудиовиджет. Это единый закреплённый блок плеера; видео YouTube не скрывается и не извлекается в аудио. Spotify и YouTube помогают находить точные совпадения; их ограничения воспроизведения сохраняются.

## Запуск

Нужен Python 3.11+, Node.js и токен бота от [@BotFather](https://t.me/BotFather). Node.js используется `yt-dlp` для поиска на YouTube и SoundCloud (метаданные, без загрузки). На Railway Mini App использует домен из переменной `RAILWAY_PUBLIC_DOMAIN`; бот сам настраивает кнопку меню при запуске. Локально публичный адрес можно указать в `WEBAPP_URL`. Дополнительно укажи `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` для Spotify, а `JAMENDO_CLIENT_ID` — для CC0-треков, которые разрешено скачивать.

```powershell
if (!(Test-Path .env)) { Copy-Item .env.example .env }
# Впишите настройки в .env, не публикуйте этот файл
python -m pip install -e .
python -m bamboook
```

Данные хранятся в SQLite (`data/bambook.sqlite3`). Веб-интерфейс и API Mini App обслуживает тот же процесс, что и бот; порт берётся из `PORT` или `WEBAPP_PORT` (по умолчанию 8080). Для контейнерного размещения используется `Dockerfile`, который устанавливает FFmpeg.

## Публикация Mini App и бота на Railway

`https://telegram-mini-app-development-seven.vercel.app` — только макет интерфейса, не сервер BamBook. Бот, API Mini App и библиотека запускаются одним Docker-сервисом из этого приватного репозитория. Railway выдаёт HTTPS-домен, бот автоматически использует `RAILWAY_PUBLIC_DOMAIN` для кнопки Mini App.

### 1. Подключи приватный GitHub

1. Открой [railway.com](https://railway.com) и войди через GitHub.
2. Создай **New Project → Deploy from GitHub repo**.
3. Если Railway запросит разрешение GitHub, авторизуй приложение и разреши доступ к `arsenimylnikovv-ctrl/BamBook-music`.
4. Выбери репозиторий и ветку `main`. Railway соберёт приложение из корневого `Dockerfile`.

### 2. Добавь токен и постоянную базу

1. Открой **Variables** сервиса → **New Variable**. Добавь `TELEGRAM_BOT_TOKEN` со значением токена от `@BotFather`. Не помещай его в GitHub или сообщения.
2. Создай **Volume**, подключи его к сервису BamBook и задай **Mount Path** `/var/data`.
3. Добавь переменную `DATABASE_PATH` со значением `/var/data/bambook.sqlite3`.
4. Примени переменные и volume, затем запусти deploy. Volume сохраняет SQLite-библиотеку при перезапуске.

### 3. Выдай HTTPS-домен и проверь запуск

1. Открой **Settings → Networking → Public Networking → Generate Domain** и создай домен вида `xxxxx.up.railway.app`.
2. В настройках Deploy укажи **Healthcheck Path** `/health`.
3. Примени настройки и запусти **Redeploy**, чтобы бот на старте увидел домен и установил кнопку меню Telegram.
4. Проверь логи: сервис должен запуститься без ошибки токена. Открой `https://<твой-домен>.up.railway.app/health`; ожидаемый ответ — `{"ok": true}`. Адрес с `/` открывает Mini App.

### 4. Открой приложение в Telegram

Бот автоматически задаёт кнопку меню. Чтобы проверить или указать её вручную: `@BotFather` → `/mybots` → BamBook → **Bot Settings → Menu Button → Configure menu button**. Задай подпись `BamBook` и HTTPS-домен Railway без `/health`. Затем открой бота, нажми **Start** или отправь `/start`, и открой кнопку возле поля ввода. Кнопку на профиле можно отдельно настроить через **Configure Main Mini App**, это необязательно.

Spotify подключается переменными `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` в Railway → **Variables**, после чего нужно развернуть сервис заново.

Jamendo подключается переменной `JAMENDO_CLIENT_ID` в Railway → **Variables**. Создай приложение в [Jamendo Developer Portal](https://devportal.jamendo.com/), скопируй выданный Client ID и добавь его в Railway. После redeploy бот будет искать и отправлять только треки с лицензией CC0, для которых Jamendo явно разрешил скачивание. Без этой переменной поиск просто не включает Jamendo.

Для BamBook Plus добавь `PREMIUM_PRICE_STARS` со значением `100` в Railway → **Variables**, затем сделай Redeploy. Оплата цифровой подписки проводится Telegram Stars; в боте доступны `/premium`, `/terms` и `/paysupport`. `/paysupport` объясняет пользователю, как самостоятельно отменить продление и обновить статус подписки.

### Стоимость

Railway даёт ограниченный бесплатный кредит для пробного запуска. Для постоянной работы рассчитывай минимум на план Hobby — **$5/месяц**, в который включено $5 потребления ресурсов; превышение оплачивается отдельно. Следи за usage и лимитом расходов в Railway. [Тарифы и правила оплаты Railway](https://docs.railway.com/pricing).

Apple Music/iTunes, Spotify и YouTube Music помогают находить карточки и точные совпадения, но не предоставляют BamBook полные коммерческие записи. Jamendo отдаёт файл только если правообладатель разрешил скачивание и лицензия — CC0. Ссылки в сообщениях поиска бота не отправляются.
## Структура

- `bamboook/bot.py` — Telegram-команды, аудио и запуск веб-сервера.
- `bamboook/catalog.py` — поиск по каталогу.
- `bamboook/webapp.py` и `bamboook/web/` — API и Telegram Mini App.
- `bamboook/storage.py` — пользовательские библиотеки и ссылки импорта.
- `bamboook/providers.py` — распознавание ссылок и заготовка адаптеров сервисов.
